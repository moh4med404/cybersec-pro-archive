# File Cleaner Script

This CMD script removes temporary (`.tmp`) and log (`.log`) files from a specified folder.

## Features

- Prompts for a folder path.
- Deletes `.tmp` and `.log` files only.
- Leaves other files untouched.

## How to Use

1. Download `file_cleaner.bat`.
2. Open Command Prompt and navigate to the script location.
3. Run the script:

```cmd
file_cleaner.bat
```
