# Folder Backup Script

This CMD script allows you to backup a folder to a specified destination.

## Features

- Prompts for a **source folder**.
- Prompts for a **destination folder**.
- Copies all files and subfolders.
- Does not overwrite the source folder.

## How to Use

1. Download `backup_folder.bat`.
2. Open Command Prompt and navigate to the folder where the script is.
3. Run the script:

```cmd
backup_folder.bat
```
